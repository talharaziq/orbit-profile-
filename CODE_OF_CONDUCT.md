# Code of Conduct

We want participation in Orbit to be respectful and practical. Be considerate, give feedback about the work rather than the person, and help keep discussions focused on improving the project.

Harassment, insults, discriminatory language, doxxing, and posting another person's private data are not acceptable. Maintainers may edit or remove content that violates these standards and may restrict participation when needed.

Report conduct concerns privately to the repository maintainer.
